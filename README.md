# 习惯打卡 · Habit Tracker

一个 HTML 文件就是一个习惯打卡工具。不用安装、不用注册、不联网，**数据只存在你自己的浏览器里**。

在线地址：https://sanfenzhongfu.github.io/habit-tracker/
英文版地址：https://sanfenzhongfu.github.io/habit-tracker/en/

页面的右上角可以一键切换中英文，两个版本共用同一份打卡数据。

## 能做什么

- **打卡**：点一下习惯卡片就完成今天的打卡，再点一下取消
- **进度环**：顶部圆环显示今日完成比例
- **连续天数**：自动统计每个习惯连续打卡了多少天，满 7 天会标记「状态不错」
- **最近 7 天**：柱状图回看一周的完成情况，并显示完成率和全勤天数
- **全部完成**：当天全部打卡完成时会有一小段撒花动画
- **自定义**：习惯名称、图标、颜色都能改，也能删除
- **自动跨天**：页面开着过零点也会自动刷新成新的一天

## 怎么用

### 在线版

用浏览器打开上面的地址即可，手机、平板、电脑都行。

建议加到手机主屏幕，用起来跟 App 差不多：
- iPhone：Safari 打开 → 分享按钮 → 「添加到主屏幕」
- 安卓：Chrome 打开 → 右上角菜单 → 「添加到主屏幕」

### 本地版

把 `index.html` 下载下来，双击用浏览器打开。

## 数据存在哪

**数据只存在你自己的浏览器里**（localStorage），不会上传到任何服务器，也不需要注册登录。

这意味着：

| 情况 | 结果 |
| --- | --- |
| 关掉页面再打开 | 数据还在 |
| 换一个浏览器打开 | 看不到之前的数据 |
| 手机和电脑各用各的 | 两边数据不互通 |
| 清理浏览器数据 / 用无痕模式 | 数据会丢失 |

所以**建议固定用一个浏览器、一台设备**来打卡。

如果将来需要跨设备同步，就得加后端和账号了——目前是纯前端，没有这一步。

## 项目结构

```
.
├── index.html      # 中文版（HTML + CSS + JavaScript 都在一个文件里）
├── en/
│   └── index.html  # 英文版
├── README.md       # 简体中文
├── README.en.md    # English
└── LICENSE         # MIT
```

没有依赖、没有构建步骤、没有框架。改完保存，刷新页面就能看到效果。

数据存储格式：localStorage 的 `habit-tracker-v1` 键下存一个 JSON，包含 `habits`（习惯列表）和 `records`（按日期索引的打卡记录）。

## 设计说明

视觉上走的是克制路线：近黑底色、极细描边、单一香槟色点缀，避免高饱和配色和过度动效。动效统一使用 spring 曲线 `cubic-bezier(.22, 1, .36, 1)`。
